# Qudrat AI Agent

Интеллектуальный Telegram-бот на базе **Google Gemini API** (`google-genai` SDK) и фреймворка **aiogram 3**.

---

## 🚀 Возможности

### 🎭 3 режима работы (`/mode`):
1. **⚡ Эффективный Агент (`agent`)** — быстрое решение задач, декомпозиция, суть без «воды», приоритет инструментам.
2. **🤝 Коллега / Друг (`friend`)** — живой, эмпатичный диалог, простые аналогии, дружелюбный тон.
3. **📊 Аналитический Эксперт (`analyst`)** — строгая опора на факты (RAG), критическое мышление, структура «Итог -> Анализ -> Рекомендация».

### 🛠 Инструменты (Function Calling):
- **`search_web`** — поиск свежей информации и новостей в сети Интернет.
- **`read_knowledge_base`** — поиск ответов по документам из локальной папки `./knowledge_base/`.
- **`execute_python_code`** — безопасное выполнение Python-кода для безошибочных расчетов и аналитики данных.
- **`save_memory`** — долговременное запоминание фактов и предпочтений пользователя в `user_memories.json`.

---

## 📌 Команды бота

- `/start` — выбор языка (🇺🇿 O'zbekcha / 🇷🇺 Русский), принятие оферты и запуск.
- `/mode` — интерактивный выбор одного из 3 режимов работы.
- `/memory` — просмотр сохранённых фактов о пользователе и кнопка очистки профиля.
- `/clear` — очистка текущего контекста диалога.
- `/help` — подробная справка о возможностях и инструментах.

---

## ⚙️ Установка и запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Заполните `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   GEMINI_API_KEY=ваш_ключ_gemini
   GEMINI_MODEL=gemini-3.8-flash
   ```

3. Запустите бота:
   ```bash
   python bot.py
   ```
   или через `run.bat` (для автоперезапуска на Windows).
